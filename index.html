Prices are Scryfall's latest known USD market price, which Scryfall sources from TCGplayer, and refresh each time you load this page. Your check marks sync through your own private cloud database, using the sync code shown above — enter that same code on any device to see the same checklist there. Cards available in both finishes get separate Regular and Foil checkboxes, and only fade once both are checked — check just one and it stays active. Prices are listed separately when regular and foil differ. Use the finish dropdown in the toolbar to filter down to foils, foil-only prints, or regular-only prints. To print a placeholder for your binder: tap Print on any card and print at actual size / 100% (no "fit to page") — it's sized for a standard 2.5″×3.5″ card sleeve. Not planning to collect a card? Tap Don't collect on it — it drops off the checklist and out of the running totals. Tap Not collecting (N) in the toolbar any time to see everything you've set aside and bring one back.
